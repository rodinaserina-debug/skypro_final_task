Git

  • git init – создает новый локальный репозиторий Git в текущей папке.
  • git clone – копирует удаленный репозиторий (например, с GitHub) на ваш компьютер.
  • git status – показывает текущее состояние: какие файлы изменены, добавлены или готовы к сохранению.
  • git add <файл> – добавляет изменения указанного файла в следующую версию (коммит).
  • git add . – добавит все измененные файлы.
  • git commit -m "Сообщение" – сохраняет добавленные изменения в истории репозитория с кратким пояснением.
  • git log – показывает историю коммитов (автор, дата, хеш, сообщение).
  • git branch – список всех веток. Текущая ветка помечена звездочкой.
  • git branch <имя> – создает новую ветку.
  • git checkout <имя> – переключается на другую ветку.
  • git push – отправляет локальные коммиты в удаленный репозиторий.
  • git pull – подтягивает изменения из удаленного репозитория в локальный.
  • git reset – отменяет добавление файлов (git add) или возвращает файлы к состоянию последнего коммита.
  • git remote add origin – связывает локальный репозиторий с удаленным.
